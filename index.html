使用教程

游戏源码为 Python 文件，请按以下步骤配置环境：

  • ① 下载 Python 3.x
  • ② 配置 Python 环境
  • ③ 下载 Pygame
  • ④ 将默认打开方式设为 IDLE
  1. 打开 Python 官网，找到 3.x 版本下载（Win7 最多支持到 3.8，建议下载 3.8 及以下版本）。
  2. 运行安装包，务必勾选 "Add Python 3.x to PATH"（配置环境），选择 "Customize installation"（自定义安装）。请记住安装路径，建议直接装到桌面。
  3. 按 Win+R 打开运行，输入 cmd，在命令行中输入 python --version，显示版本号即表示环境配置成功。
  4. 在命令行中输入 pip install pygame 等待安装。若出现红色 "pip……" 错误，说明环境变量未配置成功，请返回第 2 步检查。
  5. 右键 .py 文件 → 打开方式 → 选择默认程序 → 在这台电脑上选择更多应用。
  6. 找到 Python 的安装目录，选择 IDLE 并确认。
✅ 最后，双击 .py 文件即可运行，祝你玩得开心！
