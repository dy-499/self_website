使用教程

‘个人小游戏’所有源码都为python文件 需在python3.x环境、pygame下运行

  • 下载python3.x
  • 配置python环境
  • 下载pygame
  • 将打开默认应用换为IDLE打开
  1. 打开python官网，找到3.x版本下载（win7最多支持到3.8，所以尽量下载3.8及以下版本）
  2. 下载后打开安装包，按照教程点下面的"Add Python 3.x to PATH"（配置环境） "Customize installation"（自定义安装）！！！一定要记住选择的安装地址，实在不行就装到桌面
  3. 输入win+r 打开cmd 输入：python --version 显示python版本号即为成功
  4. 输入“pip install pygame”等待安装 如果显示“pip.....的红字”就是配置环境没成功
  5. 右键python文件：选择打开应用->默认应用->在这台电脑上选择更多应用
  6. 找到python的下载地址->选择IDLE->确认
最后，左键双击python文件运行，你就可以玩了！！！
